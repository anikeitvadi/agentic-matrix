- SAW scoring engine with weight derivation from user responses
- Results page showing ranked platform recommendations
- Comparison matrix with sortable columns and filtering
- Decision audit trail explaining score differences
  </what-built>
  <how-to-verify>
1. Start dev server: `npm run dev`

2. Navigate to http://localhost:3000/assessment

3. Complete the assessment questionnaire:
   - Step 1 (Basics): Select a use case, organization size, industry
   - Step 2 (Current State): Indicate existing platform, current stack
   - Step 3 (Requirements): Select primary use cases, compliance needs
   - Step 4 (Constraints): Set budget range, timeline, team technical level

4. Submit the assessment - should navigate to /assessment/results

5. On results page, verify:
   - [ ] Ranked list shows platforms with scores 0-100
   - [ ] Scores vary based on your answers (not all the same)
   - [ ] Top recommendation makes sense for your inputs

6. Test comparison matrix:
   - [ ] Table shows all 5 platforms
   - [ ] Columns are sortable (click headers)
   - [ ] Each criterion column shows percentage scores

7. Test filtering:
   - [ ] Budget filter reduces visible platforms
   - [ ] Compliance filter works
   - [ ] Stack filter works
   - [ ] Filters affect both ranked list and matrix

8. Test audit trail:
   - [ ] Select a platform to see score breakdown
   - [ ] Each criterion shows normalized score and contribution
   - [ ] Comparison explanation makes sense
   - [ ] Select different comparison pair, explanation updates

9. Test edge cases:
   - [ ] Empty/minimal assessment still shows results
   - [ ] All platforms show valid scores (no NaN, no negatives)
   - [ ] Page doesn't crash on any filter combination

10. Browser back/forward works correctly
