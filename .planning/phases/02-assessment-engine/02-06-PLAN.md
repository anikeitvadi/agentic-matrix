**Start the dev server if not running:**
```bash
npm run dev
```

**Criterion 1: Multi-step questionnaire (10-15 questions)**
1. Navigate to http://localhost:3000/assessment
2. Count the total questions across all 4 steps
3. Complete each step, filling in values
4. Verify: Navigation works (Next/Back buttons)
5. Verify: Validation prevents empty required fields
6. Pass if: 10-15 questions total, can complete all steps

**Criterion 2: Save progress and resume**
1. Fill in Steps 1 and 2 partially
2. Note your current answers
3. Close the browser tab completely
4. Reopen http://localhost:3000/assessment
5. Verify: Same step restored
6. Verify: Previous answers preserved
7. Pass if: Data and step position persist across browser close

**Criterion 3: AI-powered follow-up questions**
1. Complete Steps 1 and 2
2. Click "Generate Follow-Up Questions" button
3. Verify: Questions appear (1-2 questions)
4. Verify: Questions are contextual to your answers
5. Verify: Questions have appropriate input types (not all text boxes)
6. Pass if: AI generates relevant, typed questions
7. Note: Requires ANTHROPIC_API_KEY to be set in .env.local

**Criterion 4: Conditional branching**
1. In Step 2, answer "No" to "Do you have an existing platform?"
2. Verify: Follow-up questions about existing platforms are hidden
3. Change answer to "Yes"
4. Verify: Follow-up questions appear
5. In Step 3, select HIPAA compliance
6. Verify: Healthcare-specific questions appear
7. Deselect HIPAA
8. Verify: Healthcare questions hidden
9. Pass if: Questions show/hide based on previous answers

**Build verification:**
```bash
npm run build
```
Pass if: Build completes without errors
