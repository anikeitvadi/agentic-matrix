Create `lib/assessment/conditional-logic.ts` with branching rules.

Define the conditional rules for the assessment:

**Rule 1: Existing Platform Details**
- Show "existingPlatforms" multi-select only if hasExistingPlatform === true
- Show "painPoints" textarea only if hasExistingPlatform === true

**Rule 2: Use Case Specific Questions**
- If useCase === 'vendor-selection': Show "vendorCriteria" and "evaluationTimeline"
- If useCase === 'implementation-planning': Show "selectedVendor" and "implementationChallenges"
- If useCase === 'cost-analysis': Show "currentSpend" and "budgetConstraints"

**Rule 3: Compliance Details**
- If complianceRequirements includes 'hipaa': Show "healthcareDataTypes"
- If complianceRequirements includes 'fedramp': Show "governmentAgency"

Implementation approach using discriminated unions and explicit conditionals:

```typescript
type AssessmentContext = {
  useCase?: string
  hasExistingPlatform?: boolean
  complianceRequirements?: string[]
  // ... other fields
}

export function shouldShowField(
  fieldId: string,
  context: AssessmentContext
): boolean {
  switch (fieldId) {
    case 'existingPlatforms':
    case 'painPoints':
      return context.hasExistingPlatform === true

    case 'vendorCriteria':
    case 'evaluationTimeline':
      return context.useCase === 'vendor-selection'

    case 'selectedVendor':
    case 'implementationChallenges':
      return context.useCase === 'implementation-planning'

    case 'currentSpend':
    case 'budgetConstraints':
      return context.useCase === 'cost-analysis'

    case 'healthcareDataTypes':
      return context.complianceRequirements?.includes('hipaa') ?? false

    case 'governmentAgency':
      return context.complianceRequirements?.includes('fedramp') ?? false

    default:
      return true // Show by default
  }
}

// Get list of conditional fields and their dependencies for documentation
export function getConditionalFields(): Array<{
  fieldId: string
  dependsOn: string
  condition: string
}> {
  return [
    { fieldId: 'existingPlatforms', dependsOn: 'hasExistingPlatform', condition: 'equals true' },
    { fieldId: 'painPoints', dependsOn: 'hasExistingPlatform', condition: 'equals true' },
    { fieldId: 'vendorCriteria', dependsOn: 'useCase', condition: "equals 'vendor-selection'" },
    // ... etc
  ]
}
```

Keep it simple - explicit switch statements are more maintainable than a complex rule engine for ~10 conditional fields.
