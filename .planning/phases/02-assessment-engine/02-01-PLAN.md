Create `lib/assessment/types.ts` with shared type definitions:
```typescript
// Question field types for dynamic rendering
export type FieldType = 'text' | 'textarea' | 'select' | 'multi-select' | 'radio' | 'scale' | 'yes-no'

export interface Question {
  id: string
  text: string
  fieldType: FieldType
  options?: string[]  // For select, multi-select, radio
  required?: boolean
  placeholder?: string
}

export interface StepConfig {
  id: string
  title: string
  description: string
  questions: Question[]
}

// Context passed to AI for follow-up generation
export interface AssessmentContext {
  useCase: string
  organizationSize: string
  currentStack: string[]
  timeline: string
  budget: string
  answers: Record<string, unknown>
}
```

Create `app/assessment/schemas/step-schemas.ts` with step-by-step Zod schemas:

Design 4 core steps covering the assessment requirements:

**Step 1 - Basics (What are you trying to do?)**
- useCase: enum ['vendor-selection', 'implementation-planning', 'platform-evaluation', 'cost-analysis']
- organizationSize: enum ['1-50', '51-200', '201-1000', '1000+']
- industry: string (optional)

**Step 2 - Current State (What do you have?)**
- hasExistingPlatform: boolean
- existingPlatforms: array of strings (conditional on hasExistingPlatform)
- currentStack: multi-select ['aws', 'azure', 'gcp', 'on-premise', 'hybrid']
- integrationNeeds: multi-select of common integrations

**Step 3 - Requirements (What do you need?)**
- primaryUseCases: multi-select ['customer-support', 'data-extraction', 'workflow-automation', 'knowledge-qa', 'sales-routing', 'it-ticketing']
- complianceRequirements: multi-select ['hipaa', 'soc2', 'gdpr', 'fedramp', 'none']
- timeline: enum ['asap', '1-3-months', '3-6-months', '6-12-months', 'exploring']

**Step 4 - Constraints (What are your limits?)**
- budgetRange: enum ['under-10k', '10k-50k', '50k-200k', '200k-plus', 'unknown']
- teamTechnicalLevel: enum ['non-technical', 'some-technical', 'engineering-team', 'ai-ml-expertise']
- decisionMakers: multi-select ['it-leader', 'business-leader', 'executive', 'technical-team']

Each schema should:
- Use z.enum() for fixed options
- Use z.array(z.string()) for multi-select
- Include .optional() where appropriate
- Have meaningful error messages via .min() or custom messages
