```typescript
'use client'

import { useState, useMemo, useCallback } from 'react'

  platforms: Platform[]
  topPlatformIds?: string[]  // IDs of recommended platforms to highlight
}

export function CostCalculator({ platforms, topPlatformIds = [] }: CostCalculatorProps)
```

Implementation:

1. **State management:**
   - useState for usageParams (default: 10K conversations, ~20M input, ~5M output)
   - useMemo for estimates: calculate for all platforms when usage changes
   - useState for selectedPeriod: 'monthly' | 'yearly' | 'tco36'
   - useState for expandedPlatform: platformId | null (for detailed card view)

2. **Cost calculation:**
   - On usage change, recalculate all platform costs
   - Filter to only platforms in topPlatformIds (or top 5 by score)
   - Use memoization to avoid recalculating on every render

3. **Layout:**
   ```
   +------------------+------------------------+
   | Usage Input      | Cost Comparison Chart  |
   | Panel (sidebar)  | (main area)            |
   +------------------+------------------------+
   |        TCO Projection Chart               |
   +-------------------------------------------+
   | Platform Cards (expandable details)       |
   +-------------------------------------------+
   ```

4. **Responsive design:**
   - Mobile: Stack all components vertically
   - Desktop: Side-by-side for input + chart, full width for TCO and cards

5. **Period selector:**
   - Tabs or radio group: Monthly | Yearly | 3-Year TCO
   - Updates CostComparisonChart period prop

6. **Empty state:**
   - If no platforms have pricing data, show helpful message
   - "Some platforms require contacting sales for pricing"

7. **Section heading:**
   - "Cost Analysis" as h2
   - Subtitle: "Estimated costs based on your expected usage"
