  <behavior>
**Token Calculator:**
- calculateTokenCost(tokenPricing, usage) -> number
- Input: 1M input tokens at $3/M, 250K output tokens at $15/M -> Output: $6.75
- Input: 0 tokens -> Output: 0
- Input: undefined tokenPricing -> Output: 0

**Subscription Calculator:**
- selectTier(tiers, monthlyUsage) -> SubscriptionTier | null
- Usage 3000 conversations with tiers [1000, 5000, 10000] -> selects 5000 tier
- Usage exceeds all tiers -> selects highest tier
- No tiers provided -> returns null

- calculateSubscriptionCost(tier, usage, perConversationRate?) -> number
- Tier includes 5000 units, usage 3000 -> base price only
- Tier includes 5000 units, usage 7000, overage $2/unit -> base + (2000 * $2)

**Engineering Estimator:**
- estimateEngineeringDays(tier, complexity) -> EngineeringEstimate
- enterprise-os tier, no modifiers -> expected ~25 days
- developer-first tier with custom code -> expected ~25 days (20 * 1.25)
- Formula: (O + 4M + P) / 6

- engineeringDaysToCost(days, hourlyRate?, hoursPerDay?) -> number
- 25 days at $150/hr, 8hr/day -> $30,000

**TCO Calculator:**
- calculatePlatformCost(platform, usageParams, engineerRate?) -> CostEstimate
- Aggregates token/subscription + engineering costs
- Computes 12/24/36 month TCO projections

- generateTCOTimeline(estimate, months?) -> TCODataPoint[]
- Returns array of monthly cumulative costs
  </behavior>
